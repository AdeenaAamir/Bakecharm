# BakeCharm

BakeCharm is a bakery menu and rate list website built using HTML and CSS. The project presents bakery products and pricing in an organized format to help customers quickly browse available items.

## Technologies
- HTML
- CSS

## Features
- Categorized product listings
- Menu cards and rate lists
- Clean navigation and structured sections
- Simple and user-friendly design
- Digital showcase for bakery products

- index.html
- style.css
- images/
